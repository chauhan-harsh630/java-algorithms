## 🗺️ Recommended Learning Path

If you're **new to Java and DSA**, follow this order:

```
1. basics/          → Learn Java syntax & fundamentals
2. arrays/          → First DSA topic, easiest to visualize
3. strings/         → Builds on arrays, very interview-heavy
4. hashmap/         → Unlocks faster solutions to many problems
5. recursion/       → Foundation for trees, graphs, backtracking
6. linkedlist/      → Classic pointer-based data structure
7. trees/           → Recursion + data structure combined
```

> ✅ Don't skip `basics/` — a shaky Java foundation will slow you down later.

## 🧠 Problem Solving Approach

For each implementation:

1. **Understand** the problem.
2. **Identify** the algorithmic pattern.
3. **Implement** the solution.
4. **Analyze** time & space complexity.

**Documentation style used in every file:**

```java
// Problem: Two Sum
// Technique: HashMap
// Time Complexity: O(n)
// Space Complexity: O(n)
```

## ▶️ Running Java Programs

**Compile:**
```bash
javac FileName.java
```

**Run:**
```bash
java FileName
```

**Example:**
```bash
javac TwoSum.java
java TwoSum
```
